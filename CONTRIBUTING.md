# Contributing

Thanks for helping! This project is beginner-friendly (Hacktoberfest welcome).

1. Pick an issue labeled `good first issue` and comment that you want it.
2. Fork the repo, then create a branch: `git checkout -b feat/my-change`
3. Make one focused change. Add or update a test in `tests/`.
4. Run `python -m pytest` and make sure everything passes.
5. Open a pull request and link the issue (`Closes #N`).

Never commit API keys.
